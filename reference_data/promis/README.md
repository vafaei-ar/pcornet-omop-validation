# PROMIS reference data

This directory contains small, public-safe reference resources used to reproduce prespecified phenotype and analysis logic from the PROMIS pipeline.

Do not place patient-level data, PHI, site extracts, credentials, licensed vocabulary descriptions, or analysis outputs in this directory.

Current files:

- `lipid_corrected_by_harold.csv`: LOINC whitelist used by the PROMIS stroke phenotype evidence logic for lipid testing.

Other PROMIS support files should be added only when a validation module actually depends on them, with provenance documented here.
