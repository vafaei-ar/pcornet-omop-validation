# Historical documentation archive

Files in this directory are retained for provenance and auditability. They include interim progress notes, lock records, superseded manuscript fragments, design-development notes, and stage-specific completion records.

They are **not** the recommended collaborator reading path and should not be treated as competing current summaries.

For current interpretation, read the numbered documents in the parent `docs/` directory in order.

Historical records remain valuable when a reviewer needs to reconstruct:

- when a decision was made;
- whether it preceded or followed an outcome query;
- why a compatibility correction was introduced;
- which commit or definition hash anchored a completed stage;
- whether a result was primary, sensitivity, or post-outcome explanatory work.

Do not delete these records merely because the current numbered documentation is shorter. Their purpose is provenance, whereas the numbered docs provide the current scientific narrative.
